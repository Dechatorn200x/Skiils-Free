## 📌 เหมาะกับการทำงานด้านใด? (Use Cases)

สกิลนี้ออกแบบมาสำหรับ **Academic & Exam Preparation Cycle** ที่ต้องการค้นหา รวบรวม วิเคราะห์ และเก็งข้อสอบในวิชาต่าง ๆ จบใน Prompt เดียว เหมาะอย่างยิ่งสำหรับ[cite: 6]:

1. **การเตรียมตัวสอบวัดระดับ & สนามสอบแข่งขัน**[cite: 6]  
   *(A-Level, TPAT/TGAT, SAT, GRE, IELTS, TOEIC, หรือข้อสอบบรรจุ/รับราชการ)*[cite: 6]
2. **การสอบในระดับโรงเรียน & มหาวิทยาลัย**[cite: 6]  
   *(ข้อสอบ Midterm / Final ในสาขา วิทยาศาสตร์, คณิตศาสตร์, วิศวกรรมศาสตร์, ภาษาศาสตร์, สังคมศาสตร์ ฯลฯ)*[cite: 6]
3. **ครู ผู้สอน และอาจารย์ (Educators & Tutors)**[cite: 6]  
   *(การวิเคราะห์ Blueprint, การสกัดแนวข้อสอบเพื่อทำชีทสรุป, การเจนข้อสอบจำลอง Mock Test)*[cite: 6]
4. **การทบทวนบทเรียนเร่งด่วน (Last-Minute Revision)**[cite: 6]  
   *(สรุปสูตรลับ Short Note และจุดที่มักโดนหลอกในข้อสอบ)*[cite: 6]
